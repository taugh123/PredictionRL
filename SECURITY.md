# Sécurité / Security

## Signaler une faille / Reporting a vulnerability

Si tu penses avoir trouvé une faille de sécurité dans Prédiction RL, **ne la publie pas dans un ticket public**.
Utilise le [formulaire de signalement privé](https://github.com/taugh123/PredictionRL/security/advisories/new) :
seul le mainteneur le voit. Décris ce que tu as observé, la version concernée et, si possible, comment le reproduire.

If you think you found a security vulnerability in Prédiction RL, **do not post it in a public issue**.
Use the [private reporting form](https://github.com/taugh123/PredictionRL/security/advisories/new): only the maintainer can see it.
Describe what you observed, the affected version and, if possible, how to reproduce it.

## Versions prises en charge / Supported versions

Seule la dernière version publiée reçoit des correctifs. Les programmes installés se mettent à jour automatiquement.
Only the latest published version receives fixes. Installed programs update themselves automatically.

## Ce qui n'est pas une faille / What is not a vulnerability

Le fait que le programme ne soit pas signé (avertissement de Windows à l'installation) et que son code source ne soit
plus publié sont des choix connus.
The program not being signed (Windows' warning at installation) and its source code no longer being published are
known choices.
